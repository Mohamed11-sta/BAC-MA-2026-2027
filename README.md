Plateforme Bac Réussite 🎓 - 2ème Bac Sciences Physiques (BIOF)

Une application web interactive et moderne conçue spécialement pour accompagner les étudiants marocains de la 2ème année du Baccalauréat (Filière Sciences Physiques - Option Français) dans leurs révisions pour l'Examen National.

Créée et développée par Mohamed Amine Derouich.

🎯 Fonctionnalités Principales

Compte à rebours en temps réel : Affichage du temps restant avant la date de l'Examen National.

Tableau de bord de révision : Accès centralisé aux matières principales avec leurs coefficients.

Fiches de cours détaillées :

📐 Mathématiques : Analyse, Algèbre et Géométrie.

⚛️ Physique-Chimie : Ondes, Nucléaire, Électricité, Mécanique, Cinétique et Acido-basique.

🧬 SVT : Consommation de la matière, Génétique, Pollution.

🇬🇧 Anglais : Compréhension, Langue, Production écrite.

📖 Philosophie : Les 4 modules (Condition Humaine, Connaissance, Politique, Morale) et méthodologie.

Conseils méthodologiques : Astuces de préparation et ressources pour les anciens examens (annales).

💻 Technologies Utilisées

Ce projet est une "Single Page Application" (SPA) construite avec les technologies web standards, sans besoin de compilation complexe :

HTML5 : Structure de l'application.

JavaScript (Vanilla) : Logique de navigation entre les onglets et gestion du compte à rebours.

Tailwind CSS (via CDN) : Framework utilitaire pour un design moderne, responsive et épuré.

FontAwesome : Icônes vectorielles.

Google Fonts : Typographie personnalisée (Inter).

🚀 Comment utiliser ce projet

Le projet est extrêmement simple à lancer, aucune installation n'est requise :

Clonez ce dépôt ou téléchargez le code source.

Ouvrez simplement le fichier index.html dans n'importe quel navigateur web moderne (Chrome, Firefox, Safari, Edge).

C'est tout ! L'application fonctionne entièrement côté client.

📱 Responsivité

L'interface est entièrement responsive, ce qui signifie qu'elle s'adapte parfaitement aux écrans d'ordinateurs, de tablettes et de téléphones portables pour réviser n'importe où.
